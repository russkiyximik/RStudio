Executive Summary

Our model found that manual transmission cars have ~1.6 mpg more than automatic cars. However, the 95% CI for the effect of transmission type on MPG was approximately (-1.11, 4.30). Further, the p-value for the effect of transmission type was ~0.24. This result is not statistically significant, and we thus cannot infer that transmission type affects miles per gallon.

In practical terms, differences in mpg appear to be driven primarily by vehicle weight and engine performance characteristics, not transmission type.

Project

The objective of this project is to answer the following questions: 1. Whether automatic or manual transmission is better for MPG, and 2. Quantify the MPG difference between automatic and manual.

Model Selection

Now let us model a regression to answer our initial questions.

  1. Is an automatic or manual transmission better for MPG?

  2. Quantify the MPG difference between automatic and manual transmissions.

Since am is binary, let’s fit a generalized linear model (logistic regression) to it wrt mpg.

mod1 <- glm(formula = am ~ mpg, family = binomial, data = mtcars)

However, this is P(am | mpg), while our questions ask for P(mpg | am). Let’s make some more models.

Model 4 has a higher Adj-R^2 (it explains more variance). Model 4 beats model 2 on all above-mentioned criteria, so we will use it to test our hypotheses. Model 4 predicts that manual transmission cars have ~1.6 mpg more than automatic cars. However, our model did not find this to be statistically significant. Our 95% CI contains 0, so we cannot scientifically determine if automatic or manual transmission is better for mpg.
